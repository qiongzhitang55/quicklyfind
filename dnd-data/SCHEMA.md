# 词条统一格式（所有 dnd-data/*.json 必须遵守）

速查应用不区分数据来源，只认这一种结构。每个文件是一个**词条数组**。

## 词条结构

```json
{
  "id": "spell:火球术",
  "type": "spell",
  "name": "火球术",
  "en": "Fireball",
  "category": "3环 塑能",
  "tags": ["专注", "术士", "法师", "玩家手册"],
  "summary": "半径20尺球状，8d6火焰伤害，敏捷豁免减半。",
  "text": "三环 塑能（术士、法师）\n施法时间：动作\n……完整的规则原文……",
  "fields": { "环阶": "3", "施法时间": "动作", "施法距离": "150尺", "持续时间": "立即" },
  "source": "玩家手册",
  "cardRef": { "sheet": "法术大全", "row": 42 }
}
```

## 字段规则

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | 是 | `type:name`，全局唯一；重名时后缀 `#2` |
| `type` | 是 | `spell` / `equipment` / `feat` / `species` / `classFeature` / `magicItem` |
| `name` | 是 | 中文名，**必须与卡内写法一致**（回写卡片靠它匹配） |
| `en` | 否 | 英文名，没有就 `""` |
| `category` | 否 | 分类标签：法术=「3环 塑能」；装备=「武器/护甲/工具/冒险用品」；专长=「起源专长/通用专长/战斗风格」；种族=种族名；职业特性=「吟游诗人 3级」 |
| `tags` | 否 | 可筛选标记：职业、来源书、专注/仪式、武器精通等 |
| `summary` | 否 | 一句话摘要，界面上列表用；可为 `""` |
| `text` | 是 | **完整规则原文**，保留换行；不得截断、不得改写、不得翻译 |
| `fields` | 否 | 类别特有的结构化键值（下表），键名用中文短标签 |
| `source` | 否 | 出处书名，如「玩家手册」「塔莎的万事坩埚」 |
| `cardRef` | 是 | 回写定位：`sheet` = 工作表名，`row` = 该词条在表中的行号（1 起）；没有明确行时 `row` 填 `0` |

## 各类型的 fields 建议键名

- **spell**：环阶 / 学派 / 施法时间 / 施法距离 / 法术成分 / 材料 / 持续时间 / 仪式 / 专注
- **equipment**：类型 / 价格 / 重量 / 伤害 / 伤害类型 / 属性 / 精通 / 护甲等级 / 力量需求 / 隐匿劣势
- **feat**：先决条件 / 类别（起源专长、通用专长、战斗风格、史诗恩泽）
- **species**：生物种类 / 体型 / 速度 / 特性列表
- **classFeature**：职业 / 等级 / 子职
- **magicItem**：类别 / 稀有度

## 硬性约束

1. **不得编造内容**：`text` 必须来自卡内数据表原文（`card/grids/*.json`）；原文缺失就留 `""` 并在报告里说明。
2. **不得修改** `D:\quicklyFind\card\米瑞尔.xlsx`，只读。
3. **不得改写原文**：中文标点、换行、`\n` 一律保留。
4. 表格里 `#VALUE!`、`#N/A`、`0`、`-` 这类占位符不要当成内容。
5. 同名条目（跨书重复）保留全部，靠 `source` 区分，`id` 加 `#2` 后缀。

## 各文件

| 文件 | type | 来源工作表 |
|---|---|---|
| `dnd-data/spells.json` | `spell` | 法术大全（已完成，798 条） |
| `dnd-data/equipment.json` | `equipment` | 装备 |
| `dnd-data/feats.json` | `feat` | 专长与据点 |
| `dnd-data/species.json` | `species` | 种族 |
| `dnd-data/class_features.json` | `classFeature` | 职业 |
| `dnd-data/magic_items.json` | `magicItem` | 规则书（`城主指南2024 › 第七章：宝藏 › 魔法物品详述`，由 `tools/extract_magic_items.py` 抽出） |

> `magic_items.json` 是唯一一条**不是从卡里抽、而是从规则书语料里抽**的词条线——
> 卡里的奇物只有名字和同调，正文得从书里来（跟 `card_rules.json` 一个道理）。
