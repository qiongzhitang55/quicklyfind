# 实验区

启动法术速查填表工具的地方。双击 **`start.bat`** 即可，浏览器会自动打开 <http://127.0.0.1:8765/>。

> 想要「一个窗口、不用浏览器」的版本：双击 **`D:\quicklyFind\桌面版\法术速查填表.exe`**。
> 那是 Flutter 做的桌面壳，自己会起本目录的 `quickref.exe`，关窗就停服务。
>
> 想把这套东西拷到别的电脑 / U 盘单独跑：用 **`D:\quicklyFind\法术速查填表-便携版\`**
> （或者那个 18.9 MB 的 `法术速查填表-便携版.zip`）——界面、词条库、人物卡模板都在里面，
> 不读工作区，也不要求装 Dart / Flutter。

## 界面怎么用

```
┌──────────┬────────────┬──────────────────────┬────────────┐
│ 设计树    │ 法术列表    │  法术详情             │  备选区     │
│ 车卡顺序  │ 搜索+筛选   │  规则正文             │  待填清单    │
│          │            │  [+ 抓进备选区]       │  ──────────  │
│          │            │                      │  目标表格    │
│          │            │                      │  新建/使用已有│
│          │            │                      │  [填入表格]  │
└──────────┴────────────┴──────────────────────┴────────────┘
```

**页内的填入区已经取消了**：不管哪一页（法术、职业特性、种族、专长、各个表单），
抓到的东西、填好的字段，全都进最右边那个**备选区**，攒齐了从那儿一次写进表。
选表格（新建 / 使用已有 / 手动选择）和「填入表格」也都只在这一栏里。

最上面那一条是**车卡进度**：角色名 / 种族 / 出身 / 主职业 / 六项属性 / 技能熟练 /
专长还能选几个 / 法术位还剩几格——填好的绿、还没填的黄，点一下跳到那一页。

最左那列是**设计树**（基本信息 → 起源 → 职业 → 专长 → 装备与背包 → 魔法物品 → 法术 → 全部速查）。
带金点的是已经做好的页面：

| 页面 | 有什么用 | 写进卡里哪 |
|---|---|---|
| 基本信息 | 第一页，整张卡的主表：身份 / 等级与职业 / 兼职 / 起源 ＋ **六项属性 / 技能**（原「属性与技能」那三行并进来了） | `主要` 表（出身写 `起源` 表） |
| 法术列表 | 798 条法术，查规则、攒成一列 | `法术书` 四组法术位（共 200 格） |
| 种族背景 | 493 条种族特性 | `主要` 表特性列（种族 / 亚种在「基本信息」里定，这里只读） |
| 专长 | 229 条专长 | `主要` 表专长列 |
| 背景（起源 → 背景） | 我选的那个出身给什么，从规则书里拆出来 | 技能熟练打 `O`、工具 / 语言写「起源」表；属性值之类卡里自己算 |
| 主职业 / 子职业（职业 → 第一行） | 我选的主职业 / 子职是什么样，核心特质一条条摊开 | 技能熟练勾选后打 `O`、工具 / 语言写「起源」表；卡里自己算的只显示 |
| 职业特性（职业 → 第二行） | 到这一级为止该有哪些特性（职业 + 子职合起来），顶上顺带显示等级 / 熟练加值 | 抓进备选区，落 `主要` 表职业特性列 |
| 魔法物品 | 单节点（下面四条合过来了）：上半是**速查**——307 条魔法物品（城主指南2024），能搜名字 / 英文名 / 正文，按类别、稀有度筛，点一条看全文、右边 `+` 抓进备选区；下半是卡里那几块的编辑格 | 奇物名 `主要!L42:L51`（同调 / 稀有度 / 部位在下半部分填） |
| 全部速查（树里最后一条） | 五类词条放一起搜：法术 / 职业特性 / 专长 / 种族特性 / 魔法物品，共 3907 条；左列表（标着类别）、中正文、右 `+` 进备选区，筛选面是类型 + 来源 | 各回各家：法术→法术位、职业特性→特性列、种族→种族特性列、专长→专长列、魔法物品→奇物名列 |

> 「起源 → 其它」和「职业 → 职业特性」两栏删掉了：点上一级「起源」就是那张表单，
> 点上一级「职业」就是那个 2080 条特性的页面。设计树不用再为同一张表挂两行。
> 「属性与技能」这一支整个删了——六项属性 / 豁免 / 技能都并进第一页「基本信息」，不需要第二个入口。
> 「魔法物品」下面那四条也合成了单节点：点它就是整页。

**界面大小可以拖**：设计树 / 列表 / 备选区左边那三条竖线、「魔法物品」速查块的右边和下边，
按住拖就行；尺寸会记住（存在浏览器 localStorage 里）。

「伙伴与据点」「其他」两条删掉了（里面那几张表还没做页面）。
点节点名字 = 选中并展开，点小三角才折叠。

1. 左边点法术（或直接点条目右上角的 `+`）→ 抓进最右边的备选区
2. 备选区底部选表格：
   - **新建表格** → 弹系统「另存为」对话框，用空白模板存一份新表
   - **使用已有表格** → 弹系统「打开文件」对话框，选你的人物卡
   - 对话框打不开时点 **手动选择**，用内置目录浏览器挑
3. 点最右边的 **填入表格**：备选区里的法术依次写进表里，卡里已有的自动跳过

选过的表格会记住，下次启动直接用。

## 安全线

- **写之前自动备份**：覆盖已有文件前先存一份 `<表名>.备份-时间戳.xlsx` 在同目录（留最近 10 份）。
- **只动目标格子**：xlsx 是 zip，只替换法术名那几个 `<c>`，图片、公式、样式、数据验证原样保留。
- **失败会说出来**：表在 Excel 里开着写不进去、法术位不够、名称卡里没有，都会明说，不静默吞掉。

## 目录

```
实验区\
├─ start.bat            双击启动（推荐）
├─ start.ps1            同上，PowerShell 版
├─ reset-card.ps1       把实验卡重置回原始卡的全新副本
├─ cards\
│  └─ miriel-lab.xlsx   旧实验卡副本（现在用不用都行，界面里随便选表）
└─ out\                 自检产物与日志落这里
```

> 现在填表是**直接写进你选的那张表**（不像早先版本另存 `_填入.xlsx`），
> 所以别把 `D:\quicklyFind\card\米瑞尔.xlsx` 这类原始素材当目标，
> 要用就选 `card\悲灵.xlsx`，或者自己另存出来的副本。
